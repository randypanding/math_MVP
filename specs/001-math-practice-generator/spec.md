# Feature Specification: 数学专题练习卷生成器

**Feature Branch**: `001-math-practice-generator`

**Created**: 2026-08-11

**Status**: Draft

**Input**: User description: "基于现有数学卷子、教材和教学大纲，快速开发一个可观测的数学专题练习卷生成器。将现有材料转化为结构化的数学题库，基于题库生成可打印的专题练习卷（PDF格式），包含题目、答案及易错点分析。题目种类要丰富，覆盖小学1-6年级核心知识点，能够生成完整的练习卷子。"

## User Scenarios & Testing

### User Story 1 — 题库初始化与题目生成 (Priority: P1)

作为教师，我希望能为各年级各知识点快速生成大量结构化题目，构建初始题库。

**Why this priority**：没有题目就无法生成练习卷，程序化生成是最快速的启动方式。

**Independent Test**：运行 `mathgen generate-questions --grade 2 --kp "100以内进位加法" -n 50`，数据库中自动插入50道该知识点的题目，含答案、易错点。

**Acceptance Scenarios**:

1. **Given** 指定年级和知识点，**When** 运行题目生成命令，**Then** 系统自动生成指定数量的题目并入库
2. **Given** 指定题型（如"口算"、"竖式"、"解决问题"），**When** 生成题目，**Then** 只生成该题型的题目
3. **Given** 生成的题目，**When** 查看题目详情，**Then** 包含题干、答案、解析、易错点、难度等级

---

### User Story 2 — 练习卷生成 (Priority: P1)

作为教师，我希望能根据知识点、题型、题量等参数自动生成可打印的练习卷 PDF。

**Why this priority**：这是核心交付物，直接产生教学价值。

**Independent Test**：选择"100以内进位加法"、50题、包含答案，系统生成一份 A4 格式 PDF。

**Acceptance Scenarios**:

1. **Given** 题库中有足够题目，**When** 用户选择参数并运行生成命令，**Then** 输出包含题目、答案、易错提示的可打印 PDF
2. **Given** 选择多个知识点混合出卷，**When** 生成练习卷，**Then** 题目来自各知识点按比例分配
3. **Given** 选择多种题型，**When** 生成练习卷，**Then** 卷面按题型分板块排列
4. **Given** 题库中题目不足，**When** 用户请求题量超过库存，**Then** 系统提示可用数量并询问是否继续

---

### User Story 3 — DOC 卷子解析与入库 (Priority: P1)

作为教师，我希望能将现有 .doc 格式数学卷子转化为结构化的题库数据。

**Why this priority**：现有卷子是重要的题目来源，需要自动化处理。

**Independent Test**：运行 `mathgen extract` 处理 10 份 .doc 卷子，系统完成文本提取和图片提取，LLM 解析后输出结构化 JSON。

**Acceptance Scenarios**:

1. **Given** 用户运行 extract 命令处理 .doc 文件，**When** 系统执行文档解析，**Then** 输出包含题目文本、答案、知识点的结构化 JSON
2. **Given** 卷子中包含图形/表格，**When** 系统处理文档，**Then** 图片被提取并关联到对应题目
3. **Given** 无法确定答案的题目，**When** 系统完成解析，**Then** 答案字段标记为 null 并进入"待人工审核"队列

---

### User Story 4 — 题库审核与管理 (Priority: P2)

作为教师，我希望能方便地查看、搜索、修改已入库的题目，确保数据质量。

**Why this priority**：保证数据质量，支持长期维护。

**Acceptance Scenarios**:

1. **Given** 题库已有数据，**When** 用户按知识点/年级/题型搜索，**Then** 显示匹配题目列表
2. **Given** 题目列表，**When** 用户编辑某题并保存，**Then** 数据库更新且变更被记录
3. **Given** 用户运行 review 命令，**When** 系统显示待审核题目，**Then** 用户可逐题确认或修改

---

### User Story 5 — 错题重练 (Priority: P2)

作为教师，我希望能导入学生错题（图片或文本），系统自动识别并生成错题专项练习。

**Why this priority**：针对性教学，帮助学生攻克薄弱点。

**Acceptance Scenarios**:

1. **Given** 用户上传错题图片，**When** 系统 OCR 识别，**Then** 自动加入错题集
2. **Given** 错题集有题目，**When** 用户运行错题练习生成，**Then** 仅从错题集中抽题生成练习卷

---

### User Story 6 — 统计报告 (Priority: P3)

作为教师，我希望能查看题库统计信息和使用报告。

**Why this priority**：辅助决策，了解题库建设进度。

**Acceptance Scenarios**:

1. **Given** 系统已处理若干卷子，**When** 用户运行统计命令，**Then** 显示题库概况（总题数、知识点分布、难度分布、年级分布）
2. **Given** 处理过程中有失败记录，**When** 用户查看报告，**Then** 显示错误率和待处理项目

---

### Edge Cases

- 当 .doc 文件损坏无法打开时，系统如何处理？
- 当 LLM API 不可用时，系统是否支持离线模式（仅提取文本，不解析）？
- 当题目包含特殊数学符号（分数、根号等）时，PDF 渲染是否正确？
- 当同一题目出现在多个卷子中时，是否去重？
- 当图片题无法提取时，题目是否保留并标记？
- 当生成要求包含图形题但 PDF 无法展示时，如何处理？

## Requirements

### Functional Requirements

- **FR-001**: 系统 MUST 支持为指定知识点程序化生成题目（至少覆盖20种题型）
- **FR-002**: 系统 MUST 支持读取旧版 .doc 格式文件（Word 97-2003）
- **FR-003**: 系统 MUST 从 .doc 文件中提取嵌入的图片（图形、表格截图）
- **FR-004**: 系统 MUST 调用 LLM 将提取的文本解析为结构化题目 JSON
- **FR-005**: 系统 MUST 提供命令行交互式审核界面（查看/编辑/确认/拒绝）
- **FR-006**: 系统 MUST 将审核通过的题目持久化存储到 SQLite 数据库
- **FR-007**: 系统 MUST 支持按知识点、年级、难度、题型参数组卷
- **FR-008**: 系统 MUST 支持多知识点混合出卷
- **FR-009**: 系统 MUST 支持多种题型混合出卷（卷面按题型分板块）
- **FR-010**: 系统 MUST 生成 A4 格式 PDF（含题目、答案、易错提示）
- **FR-011**: 系统 MUST 记录处理日志和生成统计报告
- **FR-012**: 系统 MUST 标记无法自动处理的题目为"待审核"
- **FR-013**: 系统 MUST 支持知识点分级管理（年级→单元→知识点）
- **FR-014**: 系统 MUST 支持导入错题图片并加入错题集
- **FR-015**: 系统 MUST 支持仅从错题集中抽题生成专项练习
- **FR-016**: 系统 MUST 支持 LLM 模型可配置（通过配置文件切换）

### Key Entities

- **KnowledgePoint（知识点）**：知识点ID、名称、年级、单元、父知识点、题型列表
- **Question（题目）**：题干、答案、解析、易错点、难度、题型、年级、关联图片、审核状态
- **Material（原始材料）**：文件路径、处理状态、提取结果
- **Paper（练习卷）**：生成参数、题目列表、PDF路径
- **ErrorSet（错题集）**：题目ID、来源图片、加入时间、练习次数
- **ProcessingLog（处理日志）**：文件名、处理状态、提取题目数、错误信息

### Knowledge Point Coverage

系统 MUST 覆盖以下知识点范围（按年级组织）：

**一年级上册**：准备课(数一比)、1-5的认识和加减法、认识图形(一)、6-10的认识和加减法、11-20各数的认识、认识钟表、20以内进位加法

**一年级下册**：20以内退位减法、认识图形(二)、分类与整理、100以内数的认识、认识人民币、100以内的加法和减法(一)、找规律

**二年级上册**：长度单位、100以内的加法和减法(二)、角的初步认识、表内乘法(一)、观察物体(一)、表内乘法(二)、认识时间、数学广角—搭配(一)

**二年级下册**：数据收集整理、表内除法(一)、图形的运动(一)、表内除法(二)、混合运算、有余数的除法、万以内数的认识、克和千克、数学广角—推理

**三年级上册**：时、分、秒、万以内的加法和减法(一)(二)、测量、倍的认识、多位数乘一位数、长方形和正方形、分数的初步认识、数学广角—集合

**三年级下册**：位置与方向(一)、除数是一位数的除法、复式统计表、两位数乘两位数、面积、年、月、日、小数的初步认识、数学广角—搭配(二)

**四年级上册**：大数的认识、公顷和平方千米、角的度量、三位数乘两位数、平行四边形和梯形、除数是两位数的除法、条形统计图、数学广角—优化

**四年级下册**：四则运算、观察物体(二)、运算定律、小数的意义和性质、三角形、小数的加法和减法、图形的运动(二)、平均数与条形统计图、数学广角—鸡兔同笼

**五年级上册**：小数乘法、位置、小数除法、可能性、简易方程、多边形的面积、数学广角—植树问题

**五年级下册**：观察物体(三)、因数与倍数、长方体和正方体、分数的意义和性质、图形的运动(三)、分数的加法和减法、折线统计图、数学广角—找次品

**六年级上册**：分数乘法、位置与方向(二)、分数除法、比、圆、百分数(一)、扇形统计图、数学广角—数与形

**六年级下册**：负数、百分数(二)、圆柱与圆锥、比例、数学广角—鸽巢问题、整理与复习

### Question Types

系统 MUST 支持以下题型（至少20种）：

**数与代数类(14种)**：口算题、竖式计算、脱式计算、填未知数、数的组成、数的读写、比大小、规律填数、验算题、估算题、简便计算、列综合算式、解方程、百分数/折扣/税率

**几何与量类(4种)**：图形计数、周长面积计算、单位换算、角的度量

**统计与解决问题类(3种)**：统计图表分析、解决问题、数学广角(搭配/植树/抽屉)

## Success Criteria

### Measurable Outcomes

- **SC-001**: 覆盖至少 **100 个知识点**，每个知识点可生成 **≥10 种题型**
- **SC-002**: 单知识点题目生成速度 ≥ **100题/秒**
- **SC-003**: 从上传到入库的单题平均处理时间 ≤ 2 分钟（含人工审核）
- **SC-004**: PDF 生成时间 ≤ 10 秒（50题规模）
- **SC-005**: 教师可在 30 分钟内完成 10 套卷子的题目入库
- **SC-006**: 生成的练习卷可直接打印，A4 格式，中文显示正常
- **SC-007**: 初始题库（程序化生成）≥ **5000 道题**，覆盖 1-6 年级核心知识点

## Assumptions

- 用户安装了 Microsoft Word（或兼容软件）以支持 .doc 文件读取
- 用户有可用的 LLM API Key（通义千问、DeepSeek 或 OpenAI 兼容服务）
- 现有卷子的排版格式基本一致（题目编号、答案分离）
- 图片题占比较小（<20%），不影响整体题库建设
- 程序化生成的题目答案100%正确（基于数学规则生成）
- 用户具备基本命令行操作能力
- 数据隐私：所有处理在本地完成，仅 LLM 调用需要网络
